- [REQUIREMENTS.md](REQUIREMENTS.md): İşlevsel, teknik ve teslim şartları.
- [ROADMAP.md](ROADMAP.md): Aşama sırası, öncelikler ve teslim takibi.
- [AGENTS.md](AGENTS.md): Ajanın çalışma, güvenlik ve onay kuralları.
- [CURRENT_TASK.md](CURRENT_TASK.md): Onaylı görev tanımının süreç kaydı.
- [PROGRESS.md](PROGRESS.md): Uygulanan işler, doğrulamalar ve kararların ilerleme kaydı.
