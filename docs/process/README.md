# Geliştirme süreci

Bu klasör, projenin yapay zekâ ajanlarıyla tek onaylı görev, bağımsız inceleme ve push yetkisinin insanda kalması düzeniyle yürütülmesinin kayıtlarını içerir.

- [REQUIREMENTS.md](REQUIREMENTS.md): İşlevsel, teknik ve teslim gereksinimleri.
- [ROADMAP.md](ROADMAP.md): Tamamlanan aşamalar, yapılmayanlar ve olası sonraki işler.
- [AGENTS.md](AGENTS.md): Ajanın yetki, güvenlik, test ve raporlama sözleşmesi.
- [CURRENT_TASK.md](CURRENT_TASK.md): Tamamlanan son görev ve yeni görev şablonu; açık görev yok.
- [PROGRESS.md](PROGRESS.md): Tarih, commit ve kanıtlarla aşama sonuçları ve tarihsel notlar.
- [START_PROMPT.md](START_PROMPT.md): Geliştirme başında kullanılan görev metninin arşivi.
